JUNGLE MONKEY - HAND CONTROL
============================

How to play
1. Open index.html in Google Chrome (or Edge).
2. Click START and allow camera access.
3. Hold one hand up in front of the camera in good light.

Hand controls
- Open hand ............ monkey runs
- Fist ................. monkey stops
- Pinch / flick hand up  jump over logs
- Move hand left/right . switch lanes

Keyboard fallback: Up/W = run, Space = jump, Left/Right = lanes, C = recenter

Rules: eat only bananas (105 kcal each). Other fruits and logs cost a life.

Note: an internet connection is needed (3D engine and hand-tracking model
load online). If the camera does not start from a local file, run a simple
server in this folder:  python -m http.server 8000
then open http://localhost:8000
